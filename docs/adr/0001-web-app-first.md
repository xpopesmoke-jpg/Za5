# Za5 starts as an installable web app, not a native app

Za5 is built as a Next.js web app that Members add to their phone's home screen, not as a native iPhone and Android app. The first release is a private test in one Household, and a web app is the fastest way to get the core loop into real use with the same stack as our other apps. The cost: iPhone notifications only work once the app is added to the home screen (iOS 16.4 and later), and there is no App Store listing. We will revisit a native app (Expo or a wrapper) before selling to the public.
